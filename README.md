A deterministic, pure-stdlib Python program that sums up 17 November 2026's world news in a single 1600x1000 infographic image (PNG): six top stories, from the Kerch Bridge strike to the Strait of Hormuz, rendered with a hand-authored 5x7 bitmap font and a hand-written PNG encoder. No network, no dependencies, no randomness — two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes `output/image.png`.
